# Stat Block Templates

This folder contains the agreed source format for D&D 3.5 stat blocks.

## Canonical Template

`Dungeon Magazine Stat Block Template.txt` is the full ordered template exported from the Google Docs source.

Most real stat blocks may omit fields, but fields that appear should stay in this order. The parser should treat this as its contract for section order and recognized line prefixes.

## Practical Rule

When writing or editing a stat block, keep the Dungeon Magazine section order:

1. Header and identity.
2. Defense.
3. Offense.
4. Statistics.
5. Special ability descriptions.

Blank lines and separator lines are allowed between sections.
