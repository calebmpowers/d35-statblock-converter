# D35 Statblock Converter 0.3.2

Date: 2026-07-10

## File-tab usability fix

- Moves the file-conversion button into the top row of the File tab, next to the file picker.
- Labels it `Convert Selected File` so the next step is unambiguous.
- Reduces the file-path field width so the picker and conversion button remain visible at the app's minimum window size.
- Adds a short reminder beneath the preview area.

No conversion rules or Roll20 import behavior changed in this release.
