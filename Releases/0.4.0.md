# D35 Statblock Converter 0.4.0

This release makes `templates\D&D 3.5e Stat Block Template.docx` the authoritative input format.

## Highlights

- Preserves DOCX paragraph, bold-run, and italic-run structure.
- Adds first-class ordinary lower entries, a distinct lower Skills rules entry, and a structured Spell Reference without changing `schema_version: 1`.
- Links detailed spell text to upper prepared/known records without creating duplicate spells.
- Uses authoritative source spell text in repeating spell macros and retains unmatched reference material.
- Keeps Power Attack and other temporary choices out of baseline attack/damage arithmetic.
- Preserves parenthetical conditional skill totals as notes without double-counting.
- Retains legacy text fixtures and the Windows PowerShell 5.1 desktop workflow.

## Validation

The release gate covers legacy and current-format text fixtures, a DOCX fixture using the template's bold/italic run structure, payload validation, and Roll20 mock imports that inspect resulting character attributes, rules fields, spell macros, prepared counts, and token actions.
