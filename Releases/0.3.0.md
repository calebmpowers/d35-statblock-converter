# D35 Statblock Converter 0.3.0

Date: 2026-05-11

## Highlights

- Established `schema_version: 1` as the canonical Roll20 handout JSON format.
- Added a fixture-based regression suite.
- Expanded fixture coverage from simple recovered examples to harder parser cases.
- Cleaned duplicate helper definitions from the Roll20 importer.
- Added a local Windows converter app.
- Added a launcher batch file.
- Added offline payload validation.
- Bundled the Roll20 importer script in `Roll20 Importer`.

## Local App

Launch with:

```powershell
.\Launch D35 Converter.bat
```

The app supports pasted stat blocks, single-file conversion, and folder conversion.
