# D35 Statblock Converter 0.5.0 — Managed Lifecycle v1

The existing schema version 1 converter and handout workflow now support managed Roll20 Character updates inside the companion importer.

- One shared write plan drives creation, preview, update, adoption, and readback.
- Versioned ownership state tracks Character, Attribute, Ability, and repeating-row identities.
- Updates detect manual conflicts, preserve live play state and unowned content, and remove obsolete owned data.
- Explicit token binding shares the reusable token policy; portrait replacement requires `--avatar`.
- Supported default-token capture and asynchronous readback replace immediate write-success claims.
- GM authorization, operation locking, bounded journals, and pending-operation guards report partial failures accurately.
- The existing mock suite now verifies repeated managed updates, with a dedicated lifecycle regression suite.

See [Managed Lifecycle v1](../docs/managed-lifecycle-v1.md) for commands, state, recovery rules, limitations, and the proposed live acceptance procedure. No live Roll20 installation or commissioning has been performed.
