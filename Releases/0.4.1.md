# D35 Statblock Converter 0.4.1

This patch incorporates findings from the first live Roll20 import of the
authoritative DOCX workflow.

- Relies on the D&D 3.5 sheet's Initiative token action instead of creating a
  duplicate custom action.
- Ignores empty structured JSON values so they cannot appear as
  `[object Object]` in sheet text.
- Preserves parsed class names and levels in Roll20 JSON.
- Routes full Sneak Attack and Trapfinding entries to Class Abilities for
  creatures with rogue levels, without duplicating their abbreviated upper
  summaries or placing them in Racial Abilities.
- Emits each feat once, in source-list order, using its full lower entry when
  available instead of prepending a consolidated feat-name list.
- Supports `Possessions combat gear, ...` variants without creating a bogus
  `combat gear` item, and keeps expanded potion/tool rules in Other rather than
  Racial Abilities.
- Routes standard barbarian features such as Rage and Fast Movement to Class
  Abilities and recognizes combined masterwork equipment reference entries.
- Distinguishes bracketed skill tricks from feat categories and uses an untyped
  lower entry as full feat text when its name matches the upper Feats list.
- Preserves numeric thousands separators inside possession descriptions instead
  of splitting values such as `1,000 gp` into separate items.
- Routes owned-item property entries such as Cloak of Resistance and Keen to
  Other, while retaining class-feature precedence for overlapping names.
- Keeps bold temporary stat lines attached to their potion entry and routes
  standard swashbuckler features to Class Abilities.
- Routes campaign affiliation entries to Other rather than Racial Abilities.
