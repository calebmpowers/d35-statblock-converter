# D35 Statblock Converter 0.3.1

Date: 2026-07-10

## Release hardening

- Prevents accidental output and report overwrites by allocating unique filenames.
- Writes JSON, pasted input, inline commands, and reports atomically so interrupted conversions do not leave partial files.
- Verifies every app-generated handout JSON file after it is saved.
- Shows conversion failures and warning totals clearly in the app status line and batch summary.
- Separates the supported PowerShell release test path from the legacy Python comparison converter.
- Adds an explicit Node.js path option for Roll20 mock testing.
- Adds release-readiness and portable-release scripts.
- Removes stale recovery-path metadata and the broken bulk-launcher documentation.

## Verification

For a complete release check, run:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\Test-ReleaseReadiness.ps1
```

Node.js 18 or later is required only for the Roll20 mock test. It is not required to run the converter app.

## Distribution note

This release can be packaged as a portable Windows folder with `tools\New-PortableRelease.ps1`. Confirm the intended copyright, license, and third-party-content terms before distributing it publicly.
